# Emotion Detection Application

This repository contains an AI-based web application built with Python, Flask, and the Watson NLP library for detecting emotions from text.

## Features
- **Emotion Analysis**: Analyzes text to determine scores for anger, disgust, fear, joy, and sadness.
- **Dominant Emotion Identification**: Identifies the primary emotion conveyed in the input text.
- **Error Handling**: Handles blank inputs and invalid requests smoothly.
- **Flask Web Interface**: Provides a user-friendly Web GUI for real-time text analysis.

## Project Structure
- `EmotionDetection/`: Package containing the emotion detection module.
- `server.py`: Flask web server entry point.
- `test_emotion_detection.py`: Unit tests for the application.
